  **Part A — gRPC recover interceptor in grpc/server/server.go:**

  Add two new functions before the grpc.NewServer() call:

  ```go
  // panicRecoveryUnaryInterceptor recovers from panics in gRPC unary handlers,
  // logs the panic via slog, and returns a gRPC Internal status error.
  func panicRecoveryUnaryInterceptor(ctx context.Context, req any, info *grpc.UnaryServerInfo, handler grpc.UnaryHandler) (any, error) {
      defer func() {
          if r := recover(); r != nil {
              buf := make([]byte, 4096)
              n := runtime.Stack(buf, false)
              slog.Error("scout: grpc: panic recovered", "method", info.FullMethod, "panic", r, "stack", string(buf[:n]))
          }
      }()
      return handler(ctx, req)
  }

  // panicRecoveryStreamInterceptor recovers from panics in gRPC stream handlers.
  func panicRecoveryStreamInterceptor(srv any, ss grpc.ServerStream, info *grpc.StreamServerInfo, handler grpc.StreamHandler) (err error) {
      defer func() {
          if r := recover(); r != nil {
              buf := make([]byte, 4096)
              n := runtime.Stack(buf, false)
              slog.Error("scout: grpc: panic recovered in stream", "method", info.FullMethod, "panic", r, "stack", string(buf[:n]))
              err = status.Errorf(codes.Internal, "scout: grpc: internal error (panic recovered)")
          }
      }()
      return handler(srv, ss)
  }
  ```

  Wire these into the grpc.NewServer() call by adding them to the interceptor chain:
  - If ChainUnaryInterceptor already exists, prepend `panicRecoveryUnaryInterceptor` as the outermost interceptor.
  - If no unary interceptor exists, add `grpc.ChainUnaryInterceptor(panicRecoveryUnaryInterceptor)`.
  - Same pattern for stream interceptor.

  Add required imports: `"runtime"`, `"log/slog"`, `"google.golang.org/grpc/codes"`, `"google.golang.org/grpc/status"` (add only those not already imported).

  Note: the unary interceptor defer/recover does NOT currently set `err` — fix this: the deferred func must assign to a named return variable. Revise the unary interceptor signature to use named return:
